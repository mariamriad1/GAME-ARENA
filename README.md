# 🎮 GameArena

A responsive, modern front-end web application for a gaming and eSports platform. Built as a single-page marketing site with a hero banner, game showcase, team roster, and contact section — all styled with a dark, neon eSports aesthetic.

🔗 **Live Demo:** [mariamriad1.github.io/GAME-ARENA](https://mariamriad1.github.io/GAME-ARENA/)

## Project Structure

```
GAME-ARENA/
├── css/
│   ├── bootstrap.min.css
│   ├── style.css
│   └── media.css
├── js/
│   └── bootstrap.bundle.min.js
├── images/
│   └── ...
├── index.html
└── README.md
```

Tech Stack: HTML5, CSS3, Bootstrap , Font Awesome, Google Fonts (Chakra Petch & Days One), and vanilla JavaScript (via Bootstrap's bundled JS).

## Getting Started

 to run it locally:

1. Clone the repository
   ```bash
   git clone https://github.com/mariamriad1/GAME-ARENA.git
   ```
2. Open `index.html` in your browser

   or serve it locally, e.g.:
   ```bash
   npx serve .
   ```
